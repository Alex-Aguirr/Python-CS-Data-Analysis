# Python CS & Data Analysis

A structured learning repository for building a strong foundation in Python programming, computer science, and data analysis.

## Objectives

- Learn Python through computer science principles using Deitel's *Python for Programmers*.
- Learn data analysis using Wes McKinney's *Python for Data Analysis*.
- Build strong mental models instead of memorizing commands.
- Document the learning process and create reusable notes.

## Project Structure

```text
datasets/        Data files used throughout the project
deitel/          Examples and exercises from Deitel
exercises/       Additional practice exercises
mckinney/        Examples and exercises from McKinney
mini-projects/   Small projects integrating concepts
notes/           Personal notes and summaries
scratch/         Temporary experiments
tools/           Utility scripts
```

## Environment

- Miniforge
- Python 3.12
- NumPy
- pandas
- matplotlib
- VS Code
- Git

## Philosophy

Understand first. Memorize later.

Every new tool or command should answer:

1. What does it do?
2. Why are we using it?
3. How do I know it worked?
4. Where does it live?
